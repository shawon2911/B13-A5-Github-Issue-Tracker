3️⃣ What is the difference between map(), filter(), and forEach()?
ans: map() = it works on every element of an array and change the value but the main array remains immutable.
      filter() = it works on every element of an array and check a condition . and then return a new array with the elements which fulfill the condition.
      forEach() = it is used for loop through on every elements but dont return any array
